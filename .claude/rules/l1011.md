# iniBuilds L-1011 TriStar rules

Loaded when Claude reads matching code. Background: docs/l1011.md. Full text of each rule: docs/invariants/l1011.md.

- [L1011-1] A map-driven TriStar row or breaker write REPLAYS the cockpit's own click (its L:var writes, H: and K: events, in order) as ONE `ExecuteCalculatorCodeUnique` string (`L1011WritePlan`), never `SetLVar` or a bare L:var write. `L1011Levers` is the one exception; every write is refused aloud when `CalcWriteCanLand` is false. (more: see full) Full: docs/invariants/l1011.md#l1011-1
- [L1011-2] `l1011_control_map.json` is GENERATED by `tools/l1011-gen` from the aircraft's compiled cockpit behaviour and tooltips: never hand-edit it; regenerate after an iniBuilds update and review with `diff_maps.py`. iniBuilds' files and any decoded copy stay out of the repo. Full: docs/invariants/l1011.md#l1011-2
- [L1011-3] `L1011PanelLayout` and its four `L1011LayoutRows` files are the ONLY source of panel order (the manual's preflight flows), discriminator first in every name, a guard directly before its switch. `SpokenWord` sentence-cases position words but keeps single letters, words with a digit and its abbreviations in capitals. Full: docs/invariants/l1011.md#l1011-3
- [L1011-4] A transition carrying a TOGGLE K: event is REFUSED while the current position is unknown, and a just-commanded position is trusted for 2.5 s over the 1 Hz cache (`L1011CommandedState`): a toggle sent the wrong way inverts the switch and the system behind it. Full: docs/invariants/l1011.md#l1011-4
- [L1011-5] The warning-light flush runs in `OnContinuousBatchDelivered`, OUTSIDE MainForm's mute wrap, so it checks `L1011DisabledMonitorVariablesSet` itself; lever call-outs speak inside `ProcessSimVarUpdate`, inside the wrap. A context reset wipes the baselines and `Md11SeedGate` decides the re-seed, never a wall clock. Full: docs/invariants/l1011.md#l1011-5
- [L1011-6] The 981 circuit breakers are NEVER data definitions (the 1,000 budget): the breaker window reads them in one Coherent evaluation of `L1011_ENGINEER_PANEL`. Every row carries its number; the window re-filters only on open, search, the pulled-only filter and Refresh, never after a pull or push. (more: see full) Full: docs/invariants/l1011.md#l1011-6
