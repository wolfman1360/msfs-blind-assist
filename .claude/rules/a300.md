# iniBuilds A300-600 rules

Loaded when Claude reads matching code. Background: docs/a300.md. Full text of each rule: docs/invariants/a300.md.

- [A300-1] Every map-driven A300 row fires its OWN B: event, `value (>B:AIRLINER_<Name>_Set)`, through `ExecuteCalculatorCodeUnique` (`A300WritePlan`), never `SetLVar`. A two-position switch's Set FLIPS it whatever the value, so send it only from a KNOWN, differing position (`A300CommandedState`), else refuse aloud. (more: see full) Full: docs/invariants/a300.md#a300-1
- [A300-2] `a300_control_map.json` is GENERATED by `tools/a300-gen` from the aircraft's behaviour file and tooltips: never hand-edit it; regenerate after an iniBuilds update and review with `diff_maps.py`. iniBuilds' files and any decoded copy stay out of the repo. Full: docs/invariants/a300.md#a300-2
- [A300-3] `A300PanelLayout` is the ONLY source of A300 panel order: placement follows iniBuilds' component tree, order is `A300PanelLayout.Order.cs` (`PanelOrder`, `LeadRows`), unlisted panels and rows follow the listed ones, never dropped; names live in `A300PanelLayout.Names.cs`. Guard covers are never rows. (more: see full) Full: docs/invariants/a300.md#a300-3
- [A300-4] The MCDU screens are client data `iniAirbusMCDU_1`/`_2`, published only while `L:INI_MCDU_OPTION` is 1, so the window writes it on EVERY open. One `A300McduDataManager` per connection, snapshot on a DIFFERENT request id; read glyphs via `A300McduText.Glyph`; keys through ONE queue; never CLR an empty scratchpad. (more: see full) Full: docs/invariants/a300.md#a300-4
- [A300-5] A300 typed values go only through `A300TypedValues`: NAV frequencies as their `_MHZ`/`_KHZ` L:var parts; a speed in the other unit sends SPD/MACH, WAITS `ModeSwitchSettleMs`, then writes, never in one string; altimeters are `index value (>K:2:KOHLSMAN_SET)`, index FIRST. Full: docs/invariants/a300.md#a300-5
- [A300-6] `coherent-a300-efb-agent.js` presses with ONE click event at `A.pressTarget` (where a finger would land), never on the stamped control alone; never requires size on a container, never `focus()`es a field, never reads a password; overlays are found with `A.shown` and read ALONE. (more: see full) Full: docs/invariants/a300.md#a300-6
- [A300-7] Master warning and caution speak only as they come ON (the press writes 0 to the same var). Lamps and the four announced levers speak from `ProcessSimVarUpdate` inside MainForm's mute wrap (`DefAnnounceMuteSets` lists `INI_A300`); a context reset wipes the baselines and `Md11SeedGate` decides the re-seed. Full: docs/invariants/a300.md#a300-7
- [A300-8] A300 display readers read ONLY aircraft variables and stock SimVars, never the sim's memory, a picture or AI (owner's rule, 2026-10-04): the E/WD memos and warnings and the ND waypoint name and bearing are not read. Never complete them that way without asking the owner again. Full: docs/invariants/a300.md#a300-8
- [A300-9] `A300Fma` transcribes PFD::drawFMA (v1.0.11); change a word only from a new characterisation. It is composed at the end of the ONE batch carrying all 27 sources (`DeferredFlushWatchVariable`): a new batch-covered A300 var can split it, so give it its own subscription. It checks `IsMuted` itself. (more: see full) Full: docs/invariants/a300.md#a300-9
- [A300-10] A300 display boxes: green dot, S and F only at the flap positions the tape draws them; VMAX is `INI_max_speed`, not `INI_VMAX_SPEED`; the standby altimeter is `INDICATED ALTITUDE:3`; the ILS is NAV 3; tank weights are KILOGRAMS. An ECAM page lists only what its drawing routine prints, never a guess. Full: docs/invariants/a300.md#a300-10
- [A300-11] `A300TakeoffCallouts` takes V1/VR from `INI_V1_FMGS`/`INI_VR_FMGS`, and V2 from `INI_V2_FMGS` only when `PlausibleV2` accepts it (VR to VR+30), because it FOLLOWS the FCU speed window; never announce its changes. Drop the arm on every context reset and reconnect, never the speeds. Full: docs/invariants/a300.md#a300-11
- [A300-12] `A300FaultLights` (58) stream on their OWN subscriptions, never the batch (it would split the FMA). Collect a change only while `announcer.Suppressed` is false and its light's own Ctrl+M row is ticked ([A300-23]), speak it at batch end as one sentence (`A300LampCallouts`), and name a light from the cockpit node it lights, never its variable alone. Full: docs/invariants/a300.md#a300-12
- [A300-13] `A300EngagementTracker` is silent for MSFSBA's own pick, judged by `A300CommandedState` (2.5 s), never by a cache compare. Its Ctrl+M rows ride `INI_AUTOPILOT_DISCONNECT`/`INI_AUTOTHROTTLE_DISCONNECTED`, registered only to carry the rows; nothing reads their unmeasured values. Full: docs/invariants/a300.md#a300-13
- [A300-14] Only the A300 altitude window speaks on its own (`A300FcuWindows`): the autopilot also writes the heading, speed and V/S windows, so their changes are not anyone's. A panel knob step is read back once it lands; MSFSBA's own typed altitude or altitude step mutes the call-out for 2.5 s. Full: docs/invariants/a300.md#a300-14
- [A300-15] The A300 decision height is `L:INI_MINIMUMS_PILOT`/`_FO`, written directly by the typed box; the DH knob moves it only while `L:INI_DH_SELECTED` is 1 and steps the flight path angle otherwise, so never set it through the knob. Full: docs/invariants/a300.md#a300-15
- [A300-16] The altimeter knob PULL is STD and PUSH is QNH (`XMLVAR_Baro1/2_Mode` 1/0), but STD is a FLAG ONLY: the setting does not change. Ctrl+B's STD (`A300Baro`) pulls only sides in QNH (a pull saves the setting in `INI_BARO1/2_PRESSURE`) and writes 1013.25; QNH restores the saved setting. (more: see full) Full: docs/invariants/a300.md#a300-16
- [A300-17] Every A300 value box is one `ValueInputForm` type and `ShowTrackedWindow` keys on the type, so `ShowValueDialog` closes an open box with another title first (`A300AutoflightWindows.ReplacesOpenBox`); never show a value box through `ShowTrackedWindow` alone, or Ctrl+H re-shows an open speed box. Full: docs/invariants/a300.md#a300-17
- [A300-18] Autoflight window labels are the panel row's name plus the knob's own push/pull words from the map's `action` (`A300AutoflightWindows.LabelFor`), never hand-typed; each control sits in one window only, and every press goes through the row's write path (`HandleUIVariableSet`, `PressRow`). Full: docs/invariants/a300.md#a300-18
- [A300-20] An autobrake button's label is its lamp (`A300Autobrake`): "Armed" while `INI_AUTOBRAKE_LEVEL` is its level, "Decel" while its `INI_AUTOBRAKE_*_DECEL` is lit, else "Off"; never `INI_autobrake_armed`, which only the button handlers write, so the aircraft's own disarm leaves it 1. Never block a press of the active level (the aircraft disarms it). Full: docs/invariants/a300.md#a300-20
- [A300-21] A TRP button's label is its lamp, `INI_TRP_MODE` == its number (1 TOGA, 2 MCT, 3 CL, 4 CR, 5 AUTO, 6 FLEX TO; `A300Trp`); AUTO stays 5 while `INI_TRP_AUTO_MODE` holds the chosen limit (1, 3, 4), so never read the limit as a lit button. The N1 limit (`INI_THRUST_MAXIMUM_N1`) is read only on GE engines (`INI_IS_PW` 0); PW's TRP shows EPR. Full: docs/invariants/a300.md#a300-21
- [A300-22] Ctrl+B's one mode button reads the REPORTED modes (`A300Baro.ModeState`, each side while they differ) and runs STD only from both QNH, else QNH; a typed value first pushes every side in STD and confirms it reads QNH (`PressKnobsAsync`), else names that side and writes nothing; an unread mode or a running sequence is refused aloud. Full: docs/invariants/a300.md#a300-22
- [A300-23] An A300 light speaks, and its status box reads On, only as the cockpit lights it: its state AND its bus's light power (`INI_AC/DC_LIGHTS_FAILURE`, 1 = powered; each `A300FaultLights` entry names its bus from the emissive code), decided for the fault and autobrake lights by ONE `A300LampBoard`; an unread input sets no baseline. Full: docs/invariants/a300.md#a300-23
- [A300-24] A300 light changes reach speech only through `A300LampSpeech`: netted per light (on then off says nothing) and held `SettleMs` after either bus's light power flips (`A300LampBoard.PowerFlips`), because the power flag and the faults arrive on separate once-a-second subscriptions; never announce a board change directly. Full: docs/invariants/a300.md#a300-24
